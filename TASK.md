# Постановка задачи

Создать универсальную русскоязычную форму для упражнения психолога: для каждого слова отметить, вспоминается ли ситуация переживания этого чувства/состояния. Форму должно быть удобно передавать психологам и другим клиентам.

## Требования
- Сохранить порядок, формулировки, разделы и распределение исходной таблицы: пять колонок «Гнев», «Страх», «Грусть», «Радость», «Любовь»; отдельный блок «Мысли (или состояния человека), вызванные гаммой чувств» с тем же распределением колонок; отдельный список страхов.
- Текущая транскрипция: `tests/source.json`. Повторы — отдельные позиции, составные ячейки не разделять. Проверить транскрипцию по исходному изображению при наличии доступа; это не независимая проверка, если сравнить код только с JSON.
- Компактная адаптивная мобильная форма, без горизонтальной прокрутки. На широком экране сохранить пять колонок. На телефоне удобны сворачиваемые группы.
- Три состояния: без ответа, вспоминаю, пока не вспоминаю. Необязательная заметка к каждому слову; индикаторы прогресса.
- Автосохранение только на клиенте. Продолжение по той же ссылке в том же браузере и на том же устройстве. Целевая совместимость: iPhone Chrome/Safari, Android и настольные браузеры.
- Экспорт читаемого текста для психолога; JSON для резервной копии и восстановления. Подтверждение замены заполнения при импорте и очистке.
- Явный дисклеймер: локальные данные могут быть удалены браузером; для длительного хранения рекомендуется скачивать резервную копию. Ссылка передаёт пустую форму, а не чужие ответы; экспортированные файлы конфиденциальны.
- Без аналитики, сторонних шрифтов, скриптов и отправки ответов на сервер. Не включать ответы в URL.
- Безопасно обрабатывать повреждённое/запрещённое/переполненное хранилище, конфликт вкладок, некорректный импорт, XSS. Не уничтожать молча старые данные.
- Публикация отдельного публичного репозитория и GitHub Pages разрешена. Публичными должны быть только приложение, техническая документация и синтетические тесты, не персональные ответы.

## Приёмка
1. Состав и структура таблицы сверены.
2. Работают ввод, перезагрузка, прогресс, JSON round-trip, TXT, очистка и подтверждения.
3. Проверены ошибки storage/import и отсутствие отправки ответов.
4. Нет переполнения при ширинах 320, 390, 768, 1440; элементы удобны для касания/клавиатуры.
5. Проверены Chromium и WebKit; реальную проверку iPhone не подменять эмуляцией.
6. HTTPS-сайт открывается после публикации; сохранение и экспорт повторно проверены на реальном URL.
